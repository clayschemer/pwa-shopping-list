Navigation & Flow Rework — Mocks

Click-through mocks for the proposed nav rework. The aim is to evaluate how the changes feel before any Angular code is touched. Each mock is a single phone-screen snapshot; cross-page links stand in for real navigation. Style approximates the M3 light theme — exact spacing, motion, and component fidelity come in the implementation phase.

Per the plan: the drawer becomes a navigation hub, the top-bar right slot moves from Settings to a filter sheet, and Categories & Stores each get a dedicated full-screen view where rows are draggable and tap-to-edit opens an action sheet.
